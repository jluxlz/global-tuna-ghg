# Start here

Download and extract the single complete ZIP linked in README.md. Run `python restore_data.py --verify` and `python reproduce.py verify`. Install the Python/R dependencies, then run `python reproduce.py figures` for saved-result plots. Follow REPRODUCING.md for full model recalculation and optional matched-catch or regional reruns. No older archive is required. Primary scenarios are C/F/T; archived fixed-target comparators are supplementary evidence only.
